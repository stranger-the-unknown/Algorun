# Cases of the algorun-lang conformance suite where the game differs on
# purpose (L3). Format: <file>[#<case id>]  <reason>. `tool/conformance.dart
# --known` fails when a case listed here starts to agree, or when a case not
# listed here differs.
#
# All of them are the number model, which the game has not taken:
#   D2  a result outside signed 64 bits is "This number is too big."
#   D3  DIVIDE truncates toward zero
#   D4  no fractions: a fractional literal or input is refused
# and two conversions the game keeps inside +-(2^53 - 1) so that the phone and
# the web give the same answer (docs/MILESTONE_L3.md, "Number model").
