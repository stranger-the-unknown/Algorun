# Cases of the algorun-lang conformance suite where the game differs on
# purpose (L3). Format: <file>[#<case id>]  <reason>. `tool/conformance.dart
# --known` fails when a case listed here starts to agree, or when a case not
# listed here differs.

# Since the owner's decision of 2026-11-18 the game has algorun-lang's number
# model (whole numbers, truncating DIVIDE, "This number is too big.") with one
# difference: the limit is +-(2^53 - 1), the range a browser holds exactly,
# where algorun-lang's is +-(2^63 - 1). Every case below is that one
# difference (docs/MILESTONE_L3.md, "Number model"). Before the decision
# there were 24, for three different reasons.
